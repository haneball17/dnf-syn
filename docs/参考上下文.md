# 会话压缩总结（DNF Sync Box）

  ## 1) 核心目标
  - 解决后台不可用键（Q/D/F/G/C）同步问题。
  - 已确认：这是**按键级后台过滤**，不是注入路径问题。

  ---

  ## 2) 关键结论（已验证）
  - **RawInput/DI/Win32/消息层修正都已生效**，日志显示 `SpoofWmInput` > 0。
  - **S 可用、D 不可用**；交换游戏动作绑定后仍是“绑定在 S 的动作生效”。
  - 关闭同步后 S/D 均不生效 → 后台不会自然响应。
  - 因此根因是：**游戏后台对按键本身有白名单/黑名单**。

  ---

  ## 3) 方案决策（已确认）
  - 采用 **覆盖式映射（单向替换）**。
  - 映射表（主控输入 → 从控输出）：
    - Q → Oem4
    - D → L
    - F → OemSemicolon
    - G → Oem7
    - C → Oem6
  - 同步范围：**Allkeys，但排除 F12**。
  - 新增配置字段：`MappingBehavior = "Replace"`。

  ---

  ## 4) 实现已完成（C# 同步器侧）
  已修改文件：
  - `src/DNFSyncBox/Core/KeyboardProfile.cs`
    - 新增 `KeyboardMappingBehavior`，实现 Replace 覆盖式映射逻辑。
  - `src/DNFSyncBox/Core/KeyboardProfileConfig.cs`
    - 新增 `MappingBehavior` 字段；默认配置改为“all_except_f12”。
  - `src/DNFSyncBox/Core/KeyboardProfileManager.cs`
    - 解析 `MappingBehavior`，默认 profile 更新。
  - `docs/dnf-syn_开发方案.md`
    - 文档中加入 `mappingBehavior` 说明与示例。

  **重要：dnfinput.dll 未改动** → **不需要重新编译/注入 DLL**。

  ---

  ## 5) 默认配置（CreateDefault 已更新）
  ```json
  {
    "ActiveProfile": "all_except_f12",
    "Profiles": [
      {
        "Id": "all_except_f12",
        "Mode": "Blacklist",
        "Keys": ["F12"],
        "Mappings": {
          "Q": "Oem4",
          "D": "L",
          "F": "OemSemicolon",
          "G": "Oem7",
          "C": "Oem6"
        },
        "MappingBehavior": "Replace"
      }
    ]
  }

  ———

  ## 6) 注意事项

  - 已有 %AppData%\\DNFSyncBox\\profiles.json 不会自动更新，需手动替换。
  - Replace 只在 非 Mapping 模式 下生效。
  - 目标键 Oem4/Oem6/Oem7/OemSemicolon/L 已确认后台可用。

  ———
